## 🚀 Proyecto destacado

### [Control Dimensional de Accesorios](https://github.com/bzrdub/control-dimensional-accesorios)

Aplicación web para el **control de calidad dimensional** de accesorios de tuberías HDPE y PP-RCT,
desarrollada en mi práctica profesional para reemplazar planillas Excel con macros VBA.

- **React 19 + Vite + Tailwind** en el frontend, **Django 5.2** en el backend, **SQL Server** en producción.
- **Validación normativa en el servidor**: el navegador da feedback inmediato, pero el veredicto oficial
  lo calcula el backend y guarda los límites aplicados y la versión (SHA-256) de la norma.
- Misma lógica de validación en **JavaScript y Python**, probada con los mismos casos compartidos.
- Pruebas automatizadas en ambos lados e integración continua con GitHub Actions.
